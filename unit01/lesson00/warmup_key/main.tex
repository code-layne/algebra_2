\textbf{2. Evaluate a function.} Let $g(x) = 3x - 6$. Find each output, then write it as a point
$(x, g(x))$.
\[
  g(0) = {\color{keyred}\mathbf{-6}}\;(\text{point: }{\color{keyred}\mathbf{(0,-6)}})
  \quad
  g(2) = {\color{keyred}\mathbf{0}}\;(\text{point: }{\color{keyred}\mathbf{(2,0)}})
  \quad
  g(4) = {\color{keyred}\mathbf{6}}\;(\text{point: }{\color{keyred}\mathbf{(4,6)}})
\]
For what input $x$ is $g(x) = 0$? \ans{$x = 2$ (since $3(2)-6=0$)}

\textbf{3. Spot the pattern.} The table follows a steady pattern. Fill in the missing values.

Each time $x$ goes up by $1$, $y$ goes up by \ans{$3$}. \; A rule for $y$ in terms of $x$
is $y = $ \ans{$3x + 5$}.
