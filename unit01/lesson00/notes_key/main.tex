\begin{objectivebox}
\textbf{By the end of this lesson, I will be able to\dots}
\begin{itemize}\setlength{\itemsep}{2pt}
  \item classify a real number into \emph{every} set it belongs to, and explain why a radical sign does not automatically make a number irrational;
  \item name the \emph{properties of real numbers} (commutative, associative, distributive, identity, inverse, zero) and the \emph{properties of equality} and \emph{inequality}, and say which kind changes one side and which changes both;
  \item \emph{justify} every line of a solved equation or inequality by naming the property that allowed it --- including the rule that reverses an inequality symbol.
\end{itemize}
\end{objectivebox}

\vspace{0.05in}

\begin{vocabbox}
\small
Fill in each term as we build it together.
\par\vspace{2pt}
\vocabans{Rational number}{A number that can be written as $\frac{a}{b}$ where $a$ and $b$ are integers and $b\ne0$; as a decimal it terminates or repeats.}
\vocabans{Irrational number}{A real number that cannot be written as such a ratio; its decimal never terminates and never repeats. Examples: $\pi$, $\sqrt{5}$.}
\vocabans{Closure}{A set is closed under an operation when performing that operation on members of the set always gives an answer still inside the set.}
\vocabans{Property of real numbers}{A rule for rewriting one expression as an equal expression --- it changes how something looks, not what it is. Only one side is involved.}
\vocabans{Property of equality}{A rule that produces a new equation with the same solutions by doing the same thing to both sides at once.}
\vocabans{Property of inequality}{The same idea for $<,\le,>,\ge$ --- with one exception: multiplying or dividing both sides by a negative number reverses the symbol.}
\vocabans{Counterexample}{A single case that makes a general claim false. One is enough to disprove a rule.}
\end{vocabbox}

\begin{hookbox}
Two students solved the \emph{same} inequality, $-3x>12$, and got different answers.
\begin{center}
\renewcommand{\arraystretch}{1.3}
\begin{tabular}{@{}p{0.42\linewidth} p{0.42\linewidth}@{}}
\textbf{Ana's answer:} \; $x>-4$ & \textbf{Ben's answer:} \; $x<-4$ \\
\end{tabular}
\end{center}
Exactly one of them is right. Don't answer from memory --- figure out how we could \textbf{settle}
it.
\begin{itemize}\setlength{\itemsep}{1pt}
  \item Test $x=-10$ in the \emph{original} inequality. Is $-3(-10)>12$ true? \ans{yes, $30>12$} \\
        Whose answer contains $-10$? \ans{Ben's}
  \item Test $x=0$. Is $-3(0)>12$ true? \ans{no, $0>12$ is false} \quad Whose answer contains $0$?
        \ans{Ana's}
  \item So the correct answer is \ans{Ben's, $x<-4$}, and the other student forgot to
        \ansline{reverse the inequality symbol when dividing both sides by $-3$, a negative number.}
\end{itemize}
Testing settled \emph{this} one. But we cannot test every problem for the rest of the year. What we
need is the \textbf{rule} --- and its name. \emph{Every legal move in algebra has a name. Today we
hand out all the names.}
\end{hookbox}

\begin{notesbox}{1. The Real Number System --- and Why It Kept Growing}
Each set of numbers was invented because the one before it \textbf{could not answer a question}.
\begin{center}
\begin{tikzpicture}[scale=0.60, every node/.style={font=\footnotesize}]
  \draw[thick, forest, rounded corners=3mm] (0,0) rectangle (13,7.2);
  \node[forest, font=\footnotesize\bfseries] at (6.5,6.75) {REAL NUMBERS $\mathbb{R}$};
  \draw[thick, navy, rounded corners=3mm] (0.4,0.4) rectangle (8.4,6.1);
  \node[navy, font=\footnotesize\bfseries] at (4.4,5.7) {Rational $\mathbb{Q}$};
  \draw[semithick, charcoal, rounded corners=2mm] (0.9,0.9) rectangle (6.9,5.0);
  \node[charcoal] at (3.9,4.6) {Integers $\mathbb{Z}$};
  \draw[semithick, charcoal, rounded corners=2mm] (1.4,1.4) rectangle (5.6,4.0);
  \node[charcoal] at (3.5,3.6) {Whole};
  \draw[semithick, charcoal, rounded corners=2mm] (1.9,1.9) rectangle (4.6,3.1);
  \node[charcoal] at (3.25,2.65) {Natural};
  \node[charcoal, font=\scriptsize] at (3.25,2.2) {$1,2,3,\dots$};
  \node[charcoal, font=\scriptsize] at (6.2,1.5) {$-7$};
  \node[charcoal, font=\scriptsize] at (7.6,1.5) {$\tfrac34$};
  \node[charcoal, font=\scriptsize] at (5.1,1.6) {$0$};
  \draw[thick, goldacc, rounded corners=3mm] (9.0,0.4) rectangle (12.6,6.1);
  \node[goldacc, font=\footnotesize\bfseries] at (10.8,5.7) {Irrational};
  \node[charcoal, font=\scriptsize] at (10.8,4.4) {$\pi$};
  \node[charcoal, font=\scriptsize] at (10.8,3.4) {$\sqrt{5}$};
  \node[charcoal, font=\scriptsize] at (10.8,2.4) {$\sqrt[3]{2}$};
  \node[charcoal, font=\scriptsize] at (10.8,1.4) {$e$};
\end{tikzpicture}
\end{center}

\vspace{-4pt}
\begin{itemize}[leftmargin=1.5em, itemsep=2pt]
  \item \textbf{Natural} numbers count things: $1,2,3,\dots$ They cannot express ``none,'' so we add
        $0$ to get the \textbf{whole} numbers.
  \item Whole numbers cannot answer $3-5$, so we add the negatives to get the \textbf{integers}.
  \item Integers cannot answer $3\div5$, so we allow ratios and get the \textbf{rationals}: any
        number that can be written $\dfrac{a}{b}$ with $a,b$ integers and $b\ne$ \ans{0}. As a
        decimal, a rational number always \ans{terminates} or \ans{repeats}.
  \item Rationals cannot answer ``what is the side length of a square with area $5$,'' so the
        \textbf{irrationals} fill in the gaps. Their decimals never terminate and never repeat.
  \item Together, the rationals and irrationals make the \textbf{real numbers} --- with no number in
        both and none left over.
\end{itemize}

\vspace{2pt}
\textbf{The big idea behind the whole picture.} A set is \textbf{closed} under an operation if
performing that operation on members of the set always gives you an answer \emph{still inside} the
set. Each new set above was invented because the one before it was \emph{not} \ans{closed} under
some operation.

\vspace{4pt}
\textbf{Two traps.} A number belongs to \emph{every} set that contains it --- so $-7$ is an integer
\textbf{and} a rational \textbf{and} a real. And the way a number is \emph{written} is not what
decides:
\begin{center}
\renewcommand{\arraystretch}{1.4}
\begin{tabular}{@{}l l l@{}}
$\sqrt{9}=$ \ans{3}, so it is really a \ans{natural no.} &
$\dfrac{8}{2}=$ \ans{4}, so it is really an \ans{integer} &
$\sqrt{5}$ is \ans{irrational} \\
\end{tabular}
\end{center}
So the radical sign is \textbf{not} the test. The \ans{value} is.
\end{notesbox}

\begin{notesbox}{2. Properties of Real Numbers --- Rewriting \emph{One} Expression}
These rules let you change how an expression \textbf{looks} without changing what it \textbf{is}.
Nothing here is ``done to both sides'' --- there are no sides yet.
\begin{center}
\renewcommand{\arraystretch}{1.5}
\begin{tabularx}{\linewidth}{@{}l l X@{}}
\hline
\textbf{Property} & \textbf{In symbols} & \textbf{Example} \\
\hline
Commutative ($+$) & $a+b=b+a$ & $3+8=$ \ans{$8+3$} \\
Commutative ($\times$) & $ab=ba$ & $5\cdot 4=$ \ans{$4\cdot 5$} \\
Associative ($+$) & $(a+b)+c=a+(b+c)$ & $(2+6)+9=$ \ans{$2+(6+9)$} \\
Associative ($\times$) & $(ab)c=a(bc)$ & $(3\cdot5)\cdot2=$ \ans{$3\cdot(5\cdot 2)$} \\
Distributive & $a(b+c)=ab+ac$ & $4(x+7)=$ \ans{$4x+28$} \\
Additive identity & $a+0=a$ & \ans{$-6$} $+\ 0=-6$ \\
Multiplicative identity & $a\cdot1=a$ & \ans{$\tfrac25$} $\cdot\ 1=\tfrac25$ \\
Additive inverse & $a+(-a)=0$ & $11+$ \ans{$(-11)$} $=0$ \\
Multiplicative inverse & $a\cdot\dfrac1a=1$, $a\ne0$ & $\tfrac34\cdot$ \ans{$\tfrac43$} $=1$ \\
Multiplicative property of zero & $a\cdot0=0$ & $(x+9)\cdot 0=$ \ans{0} \\
Zero product property & if $ab=0$ then $a=0$ or $b=0$ & if $(x-2)(x+5)=0$ then $x=$ \ans{2} or $x=$ \ans{$-5$} \\
\hline
\end{tabularx}
\end{center}

\vspace{2pt}
\textbf{Careful --- these are only for $+$ and $\times$.} Commutative and associative say nothing
about subtraction or division. Prove it yourself with one example each:
\begin{center}
\renewcommand{\arraystretch}{1.4}
\begin{tabular}{@{}l l@{}}
Is $10-4$ the same as $4-10$? \; $10-4=$ \ans{6} but $4-10=$ \ans{$-6$}, so subtraction is
\ans{not commutative} &
Is $12\div 3$ the same as $3\div 12$? \; \ans{4} vs.\ \ans{$\tfrac14$} \\
\end{tabular}
\end{center}
A single example that breaks a rule is called a \ans{counterexample} --- and one is all you ever need.

\vspace{2pt}
\emph{Two notes worth keeping.} The \textbf{multiplicative inverse} rule says $a\ne0$, because zero
has no reciprocal --- and that is exactly why dividing by \ans{0} is undefined. And the
\textbf{zero product property} is the reason factoring will solve equations for you all year: zero
is the only number with that behavior, which is why we always move everything to one side and set
it equal to \ans{0} first.
\end{notesbox}

\begin{notesbox}{3. Properties of Equality --- Changing \emph{Both} Sides}
\begin{center}
\fbox{\parbox{0.94\linewidth}{\centering \textbf{The distinction that runs this whole course:}\\
Properties of \emph{real numbers} rewrite \textbf{one} expression. \\
Properties of \emph{equality} act on \textbf{both sides at once} to make a new equation.}}
\end{center}

\vspace{3pt}
An equation is a claim that the two sides are \textbf{two names for the same number}. Everything
below follows from that one idea.
\begin{center}
\renewcommand{\arraystretch}{1.5}
\begin{tabularx}{\linewidth}{@{}l l X@{}}
\hline
\textbf{Property} & \textbf{In symbols} & \textbf{What it lets you do} \\
\hline
Reflexive & $a=a$ & Any number equals itself. \\
Symmetric & if $a=b$ then $b=a$ & Write $x=5$ \emph{or} $5=x$ --- your choice. \\
Transitive & if $a=b$ and $b=c$ then $a=c$ & Chain two equalities together. \\
Substitution & if $a=b$, $a$ may replace $b$ anywhere & Swap a name for another name of the \ans{same} number. \\
Addition & if $a=b$ then $a+c=$ \ans{$b+c$} & Add the same amount to both sides. \\
Subtraction & if $a=b$ then $a-c=$ \ans{$b-c$} & Subtract the same amount from both sides. \\
Multiplication & if $a=b$ then $ac=$ \ans{$bc$} & Multiply both sides by the same amount. \\
Division & if $a=b$ then $\dfrac{a}{c}=$ \ans{$\tfrac{b}{c}$}, $c\ne$ \ans{0} & Divide both sides by the same \emph{nonzero} amount. \\
\hline
\end{tabularx}
\end{center}

\vspace{3pt}
\boxguard[14]
\textbf{Now justify a solution, line by line.} Name the property beside each step. Watch how the two
\emph{kinds} of property alternate.
\begin{steptable}
  \step{3(x-4)}{=18}{Given}
  \step{3x-12}{=18}{\ans{Distributive property (a property of real numbers)}}
  \step{3x-12+12}{=18+12}{\ans{Addition property of equality}}
  \step{3x}{=30}{\ans{Additive inverse + additive identity}}
  \step{\dfrac{3x}{3}}{=\dfrac{30}{3}}{\ans{Division property of equality}}
  \step{x}{=10}{\ans{Multiplicative inverse + multiplicative identity}}
\end{steptable}
Which lines above changed only \emph{one} side? \ans{lines 2, 4, 6} \\
Which changed \emph{both}? \ans{lines 3, 5}
\end{notesbox}

\begin{notesbox}{4. Properties of Inequality --- and the One That Reverses}
Everything from Section~3 carries over to $<$, $\le$, $>$, $\ge$ --- with \textbf{one} exception.
\begin{center}
\renewcommand{\arraystretch}{1.45}
\begin{tabularx}{\linewidth}{@{}l X@{}}
\hline
\textbf{Property} & \textbf{Effect on the symbol} \\
\hline
Add or subtract the same number on both sides & symbol \ans{stays the same} \\
Multiply or divide both sides by a \textbf{positive} number & symbol \ans{stays the same} \\
Multiply or divide both sides by a \textbf{negative} number & symbol \ans{reverses} \\
\hline
\end{tabularx}
\end{center}

\vspace{3pt}
\textbf{Why does the negative one reverse?} Start with something obviously true and watch what
multiplying by $-1$ does to it on the number line.
\begin{center}
\begin{tikzpicture}[scale=0.52]
  \numline{-11}{11}
  \fill[forest] (4,0) circle (4pt) node[above=3pt, font=\scriptsize, forest]{$4$};
  \fill[forest] (10,0) circle (4pt) node[above=3pt, font=\scriptsize, forest]{$10$};
  \fill[goldacc] (-4,0) circle (4pt) node[above=3pt, font=\scriptsize, goldacc]{$-4$};
  \fill[goldacc] (-10,0) circle (4pt) node[above=3pt, font=\scriptsize, goldacc]{$-10$};
  \draw[->, semithick, navy] (4,0.9) to[bend left=22] (-4,0.9);
  \draw[->, semithick, navy] (10,1.4) to[bend left=20] (-10,1.4);
\end{tikzpicture}
\end{center}
\begin{itemize}[leftmargin=1.5em, itemsep=2pt]
  \item Start: \; $4<10$ \; --- true, and on the line $4$ sits to the \ans{left} of $10$.
  \item Multiply both sides by $-1$: \; $-4$ \ans{$>$} $-10$? \; Check the picture: $-4$ now
        sits to the \ans{right} of $-10$.
  \item Multiplying by a negative \textbf{reflects the entire number line through zero}. Reflection
        reverses \ans{order} --- so the symbol has to turn around with it.
\end{itemize}

\vspace{3pt}
\boxguard[10]
\textbf{Back to Ana and Ben.} Now settle the Hook by name, not by testing.
\begin{steptable}
  \step{-3x}{>12}{Given}
  \steprel{\dfrac{-3x}{-3}}{\ans{$<$} $\dfrac{12}{-3}$}{\ans{Division property of inequality --- divided by a negative, so the symbol reverses}}
  \step{x}{<-4}{\ans{Multiplicative inverse + multiplicative identity}}
\end{steptable}
So \ans{Ben} was right. \quad \emph{Careful:} the symbol reverses only when you multiply or
divide \textbf{by} a negative. It does \textbf{not} reverse just because the answer happens to be
negative, and it does \textbf{not} reverse when you subtract.
\end{notesbox}

\begin{practicebox}
Justify each line, then answer the question underneath.
\begin{steptable}[Property]
  \step{-2(x+5)}{\le 6}{Given}
  \step{-2x-10}{\le 6}{\ans{Distributive property}}
  \step{-2x}{\le 16}{\ans{Addition property of inequality (added 10 to both sides)}}
  \step{x}{\ge -8}{\ans{Division property of inequality --- divided by $-2$, so the symbol reversed}}
\end{steptable}
\begin{enumerate}[leftmargin=1.7em, itemsep=3pt]
  \item The symbol reversed on the last line but not the line before it. Explain the difference
        between what happened on those two lines.
        \ansline{Line 3 \emph{added} $10$ to both sides, and adding never changes the symbol. Line 4
        \emph{divided} both sides by $-2$, a negative number, which reflects the number line through
        zero and reverses the order --- so $\le$ became $\ge$.}
  \item Classify $\sqrt{16}$ into every set it belongs to. \ans{$\sqrt{16}=4$: natural, whole, integer, rational, real}
  \item A classmate says ``$-\sqrt{4}$ must be irrational, since it has a radical \emph{and} a
        negative.'' Give the value and say what is actually true.
        \ansline{$-\sqrt{4}=-2$, which is an integer, a rational number, and a real number --- not
        irrational. Neither the radical sign nor the negative sign decides; only the \emph{value} does.}
\end{enumerate}
\end{practicebox}
