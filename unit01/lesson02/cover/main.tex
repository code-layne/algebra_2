\begin{remindbox}
\small An \textbf{absolute value} $|x|$ is a \emph{distance} from zero, so it is never negative --- and
that one fact drives everything here. \textbf{Equations:} isolate the bars, then $|ax+b|=c$ splits
into $ax+b=c$ \emph{or} $ax+b=-c$ (and if $c<0$, there is \emph{no solution}). \textbf{Inequalities:}
``less th\textbf{AND}'' --- $|ax+b|<c$ traps the expression \emph{between} $-c$ and $c$ (one
interval); ``great\textbf{OR}'' --- $|ax+b|>c$ throws it \emph{outside} (two rays). Write every
solution set three ways: \textbf{set} $\{x \mid \dots\}$, \textbf{interval} (brackets include,
parentheses exclude), and a shaded \textbf{number line}.
\end{remindbox}
