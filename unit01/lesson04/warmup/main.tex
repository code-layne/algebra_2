\emph{include} a point and an \emph{open} dot $\circ$ to \emph{exclude} it.
\begin{itemize}[leftmargin=1.6em, itemsep=4pt]
  \item Is $x=1$ a solution of $x<1$? \blank{1.4cm} \quad Is $x=1$ a solution of $x\le1$?
        \blank{1.4cm}
  \item To show $x\ge2$ on a number line, the dot at $2$ is \blank{2.0cm} (open / closed).
        To show $x>2$, it is \blank{2.0cm}.
  \item Suppose one rule is used when $x<1$ and a \emph{different} rule when $x\ge1$. The input
        $x=1$ uses \blank{3.0cm} (the first rule / the second rule / both).
\end{itemize}
