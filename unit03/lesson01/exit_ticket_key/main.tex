No notes. Show the feature you read and how you got it.

\begin{enumerate}[leftmargin=1.8em, itemsep=12pt]
  \item \textbf{Vertex form.} For $g(x) = (x+2)^2 - 1$, state the \textbf{vertex}, the \textbf{axis of
        symmetry}, whether it opens up or down, and the \textbf{minimum or maximum value}.
        \ansline{Vertex $(-2,-1)$ (from $h=-2,\ k=-1$); axis $x=-2$; opens up ($a=1>0$); minimum value $-1$.}
  \item \textbf{Standard form.} For $f(x) = x^2 - 4x + 3$, find the \textbf{axis of symmetry}
        $x=-\dfrac{b}{2a}$, then the \textbf{vertex}, and the \textbf{$y$-intercept}.
        \ansline{Axis $x=-\frac{-4}{2(1)}=2$; \; vertex $f(2)=4-8+3=-1\Rightarrow(2,-1)$; \; $y$-intercept $(0,3)$.}
  \item \textbf{SOL-style multiple choice.} The graph of $y = (x-3)^2 + 2$ is the parent $y=x^2$
        shifted:
        \begin{enumerate}[label=\Alph*., leftmargin=1.9em, itemsep=1pt]
          \item left $3$ and up $2$.
          \item right $3$ and up $2$. \textcolor{keyred}{\textbf{$\leftarrow$ correct}}
          \item right $2$ and up $3$.
          \item left $3$ and down $2$.
        \end{enumerate}
        \begin{itemize}[leftmargin=1.4em, nosep]
          \item[] $(x-3)$ moves the graph \emph{right} $3$ (the sign flips), and $+2$ moves it \emph{up} $2$; vertex $(3,2)$. \textbf{A} flips the horizontal direction; \textbf{C} swaps the shifts; \textbf{D} flips both.
        \end{itemize}
\end{enumerate}

\begin{teachernote}
Sort responses into ``got it / shift-direction slip / vertex-sign slip / $-b/2a$ slip.'' The telltale
error is item~3A (or a vertex of $(-2,\cdot)$ in item~1 read as $(2,\cdot)$) --- the horizontal sign
flip. If several miss it, reopen Lesson~3.2 by tracking one anchor point through $(x-3)^2$ on the board
before starting factoring.
\end{teachernote}
