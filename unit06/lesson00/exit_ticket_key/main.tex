\begin{enumerate}[leftmargin=1.8em, itemsep=8pt]
  \item \textbf{Read the features.} Write the domain and range in interval notation.

        Domain: \ans{$[-1,\infty)$} \quad Range: \ans{$[-2,\infty)$} \quad Endpoint: \ans{$(-1,-2)$}

        \vspace{3pt}
        $x$-intercept: \ans{$(3,0)$} \quad $y$-intercept: \ans{$(0,-1)$} \quad
        $f$ is increasing on \ans{$[-1,\infty)$}

        \vspace{3pt}
        Absolute \ans{minimum} of \ans{$-2$} at $x=$ \ans{$-1$}; \; no absolute
        \ans{maximum}.

  \item \textbf{Explain.} Why does $f$ have a restricted domain, while $\sqrt[3]{x+1}-2$ would not?
        And what happens to this graph as $x\to-\infty$?
        \ansline{$f$ has an \emph{even} index, so its radicand cannot be negative: $x+1\ge 0$ forces
        $x\ge -1$. A cube root has an \emph{odd} index, and cubing keeps the sign, so any real
        radicand is legal and the domain would be all reals.\\[3pt]
        Nothing happens as $x\to-\infty$ --- there is no left end. The graph \emph{stops} at its
        endpoint $(-1,-2)$, because every input to the left of $-1$ is outside the domain.}

  \item \textbf{SOL-style multiple choice.} What is the domain of $h(x) = \sqrt{5-2x}$?
        \begin{enumerate}[label=\Alph*., leftmargin=1.9em, itemsep=1pt]
          \item $x \ge \dfrac{5}{2}$
          \item $x \le \dfrac{5}{2}$ \quad \textcolor{keyred}{\textbf{$\leftarrow$ correct}}
          \item $x \ge -\dfrac{5}{2}$
          \item all real numbers
        \end{enumerate}
\end{enumerate}

\begin{teachernote}
\textbf{Answer 3:} B. Solve $5-2x\ge 0 \Rightarrow -2x\ge -5 \Rightarrow x\le \tfrac52$ (dividing by
$-2$ flips the inequality). Each distractor breaks exactly one idea: \textbf{A} solves correctly but
forgets the flip; \textbf{C} mishandles the signs when isolating $x$; \textbf{D} treats an even index
as if it imposed no restriction --- the cube-root confusion.

\textbf{Sort the collected tickets into four piles} to decide how Lesson~6.1 opens:
\emph{got it} / \emph{sign-flip slip} (item~3 answered A) / \emph{invented a left arm} (item~2 claims
$f\to-\infty$) / \emph{even-vs-odd index confusion} (item~2 or item~3 answered D). The last pile
matters most: Lesson~6.1 is built entirely on why an even index behaves differently from an odd one,
so if that pile is large, re-teach Warm-Up item~1 before starting $n$th roots.
\end{teachernote}
